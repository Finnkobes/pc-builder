### Beschrijving van het project

PC Builder is een webapplicatie waarmee een gebruiker zelf een computer kan samenstellen. De gebruiker kan verschillende onderdelen kiezen, zoals een processor, videokaart, RAM, opslag, moederbord, voeding en behuizing.

De website berekent de totale prijs van de gekozen onderdelen en controleert of de onderdelen met elkaar kunnen samenwerken.

### Waarom wil ik dit project maken?

Ik wil dit project maken omdat ik geïnteresseerd ben in computers en hardware. Ik vind het leuk om verschillende pc-onderdelen te vergelijken en computers samen te stellen.

Met dit project wil ik daarnaast meer leren over het maken van een webapplicatie met Python, Flask, HTML, CSS en JavaScript.

### Randvoorwaarden

* De website moet overzichtelijk en makkelijk te gebruiken zijn.
* De gebruiker moet verschillende pc-onderdelen kunnen kiezen.
* De totale prijs van de gekozen onderdelen moet worden berekend.
* De website moet controleren op belangrijke compatibiliteitsproblemen.
* De applicatie moet werken in een moderne webbrowser.
* Er mogen geen onnodige persoonsgegevens van gebruikers worden opgeslagen.

#### AVG
